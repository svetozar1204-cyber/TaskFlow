# TaskFlow

## 1. Описание на проекта

TaskFlow е уеб приложение за управление на проекти и задачи.
То позволява на потребителите да създават, преглеждат,
редактират и изтриват проекти и задачи.

## 2. Използвани технологии

- Python 3.12
- Flask
- PostgreSQL
- SQLAlchemy
- Docker
- Docker Compose
- Nginx
- HTML и CSS

## 3. Основни функционалности

- Създаване на проекти
- Редактиране на проекти
- Изтриване на проекти
- Създаване на задачи
- Редактиране на задачи
- Изтриване на задачи
- Управление на статуса на задачите
- Табло със статистика
- Системен мониторинг

## 4. Архитектура

Приложението използва Docker Compose и се състои от:

- PostgreSQL – база данни
- Flask Web 1 – първа инстанция на приложението
- Flask Web 2 – втора инстанция на приложението
- Nginx – Load Balancer, който разпределя заявките между двете инстанции

## 5. Стартиране на проекта

Необходимо е да имате инсталирани Docker и Docker Compose.

1. Клонирайте проекта.
2. Създайте `.env` файл въз основа на `.env.example`.
3. Стартирайте контейнерите:

```bash
docker compose up -d --build
```

4. Проверете състоянието им:

```bash
docker compose ps
```

## 6. Проверка на Load Balancer

Изпълнете:

```bash
for i in $(seq 1 10); do
  curl -s http://localhost:5000/health
done
```

Заявките трябва да се разпределят между `web1` и `web2`.

## 7. Проверка на HTTPS

Приложението поддържа HTTPS чрез самоподписан сертификат.

Локална проверка:

```bash
curl -k https://localhost:5443/health
```
