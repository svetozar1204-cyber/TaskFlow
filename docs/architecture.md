
# TaskFlow – Архитектура на системата

## 1. Общ преглед

TaskFlow е уеб приложение за управление на проекти и задачи.
Системата е изградена с Flask и PostgreSQL и се стартира чрез Docker Compose.

## 2. Компоненти

### Nginx
Използва се като Load Balancer. Разпределя входящите HTTP заявки между двете Flask инстанции.

### Flask Web 1
Първа инстанция на уеб приложението.

### Flask Web 2
Втора инстанция на уеб приложението.

### PostgreSQL
Релационна база данни, която съхранява проектите и задачите.

## 3. Взаимодействие между компонентите

1. Потребителят изпраща заявка към Nginx.
2. Nginx избира една от Flask инстанциите.
3. Flask обработва заявката.
4. При необходимост Flask комуникира с PostgreSQL.
5. Резултатът се връща към потребителя през Nginx.

## 4. Балансиране на натоварването

Системата използва две Flask инстанции – web1 и web2.
Nginx разпределя заявките между тях.

## 5. Сигурност

За HTTPS комуникация е конфигуриран самоподписан SSL сертификат.

## 6. Контейнеризация

Docker Compose управлява контейнерите и мрежовата комуникация между компонентите.

## 7. Мониторинг

Приложението предоставя health endpoint за проверка на състоянието на Flask инстанциите.
Има и отделна страница за системен мониторинг.
